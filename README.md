# open-desktop

Universal Control for Hyprland: push the cursor against a screen edge and it crosses to another Linux machine. Keyboard follows, clipboard syncs, files can be dragged across.

Requirements: Hyprland >= 0.56, two machines on the same LAN.

Status: work in progress. See `packaging/opendesk.service` for the systemd user unit and `opendesk --help` for the CLI.
